# FinPilot Web Prototype

Prototipo front-end de una plataforma fintech orientada a **decisiones automatizadas**.

## Lo que incluye

- Onboarding inicial obligatorio con datos clave: ingresos, gastos fijos y estado de deuda.
- Distribución del presupuesto considerando el ingreso completo (incluye gastos fijos, deuda mínima, deuda extra, ahorro e inversión).
- Reglas de decisión automáticas (avalancha/bola de nieve y cambio de etapa financiera).
- Simulación de resultados a 3, 6 y 12 meses.
- Misiones semanales accionables.
- Animaciones y transiciones para una experiencia premium.

## Ejecutar localmente

```bash
python3 -m http.server 8000
```

Luego abre: `http://localhost:8000`
